# SHIVA RAJ - React Developer Portfolio

A developer portfolio created with **React 18** and styled with an obsidian black and golden/amber aesthetic inspired by the reference design.

## Key Features

1. **Cinematic Video Intro Gateway**:
   - Before opening the main portfolio dashboard, an introductory video presentation plays (`assets/video/intro.mp4`).
   - Custom video player with Play/Pause, Mute/Unmute, interactive timeline scrubber, and fullscreen controls.
   - Includes **"Click to Unmute Audio"** badge for browser autoplay policy compliance.
   - **Auto-transition**: When the video finishes (or when the user clicks **"Enter Portfolio Dashboard"** or **"Explore Dashboard"**), the gateway fades out and reveals the portfolio dashboard.
   - **"Watch Video"** button in the dashboard navbar allows replaying the intro video anytime.
